# Character artwork

- Character: 土间埋 / Umaru Doma, from 《干物妹！小埋》 / Himouto! Umaru-chan.
- Source: [Umaru Transparent 4chan – Umaru Chan Transparent, PNGkey](https://www.pngkey.com/pngs/umaru/).
- Original asset: https://www.pngkey.com/png/full/187-1870378_umaru-transparent-4chan-umaru-chan-transparent.png
- Downloaded unchanged: 880 × 1024 pixels, RGBA PNG with actual transparency, 385846 bytes.
- Artwork is third-party character art for this personal, noncommercial fan project; it is not original project artwork or AI-generated.
- The built-in image-generation tool was attempted but returned “Image generation is not enabled for this group.” No API/CLI image-generation fallback was used. The final website uses the downloaded image unchanged.

The PNG is embedded into the standalone index.html during `node build.cjs`, so the local webpage does not depend on the image host or a separate asset file at runtime. Its small header portrait reuses the same embedded image.
